# VPN Bot Panel

Комплексная система управления VPN с интерфейсом Telegram бота и админ-панелью.

## Возможности

- 🤖 **Telegram Bot** - Управление пользователями и поддержка через Telegram
- 👑 **Админ-панель** - Безопасный веб-интерфейс для администрирования
- 💳 **Интеграция платежей** - Поддержка платежей через YooKassa
- 🔒 **Безопасность** - Защищенная база данных с аудит-логированием и шифрованием
- 📱 **Управление VPN** - Генерация и управление VPN конфигурациями
- 🔐 **Контроль доступа** - Ролевой контроль доступа для администраторов
- 📊 **Аналитика** - Статистика пользователей и отчеты по платежам
- 🎛️ **Единое меню управления** - Удобное управление через терминал с помощью `Boot-main-ini`

## Установка

### Быстрая установка (Linux)

```bash
# Скачайте и запустите установщик
wget -O install.sh https://raw.githubusercontent.com/Chistovik92/vpn-bot-panel/main/install.sh
chmod +x install.sh
sudo ./install.sh
```
### Установщик автоматически:

Клонирует репозиторий

Создаст виртуальное окружение Python

Установит все зависимости

Настроит базу данных

Проведет через создание аккаунта администратора

Настроит базовые параметры

## Ручная установка
~~~bash
# Клонируйте репозиторий
git clone https://github.com/Chistovik92/vpn-bot-panel.git
cd vpn-bot-panel

# Сделайте скрипты исполняемыми

# Запустите установку (требует root)
sudo ./install.sh
~~~

## Использование
Главное меню управления
После установки для управления системой используйте:

~~~bash
sudo ./Boot-main-ini
~~~

### Меню предоставляет следующие возможности:

Управление системой: запуск, остановка, перезапуск бота, статус системы

Управление администраторами: создание, изменение пароля, список администраторов

Настройка панели: изменение порта, URL, включение/выключение панели

Управление серверами: добавление, удаление, список серверов (интеграция с 3x-ui)

Дополнительные функции: создание ссылок подписок, настройки функций бота, резервное копирование

Системные утилиты: обновление, переустановка, удаление панели

## Запуск бота вручную
~~~bash
# Активируйте виртуальное окружение (если еще не активировано)
source venv/bin/activate  # Linux/Mac
# ИЛИ
venv\Scripts\activate     # Windows

# Запуск всего стека (бот + веб-панель)
python run.py
# Только бот
python bot.py
~~~

Доступ к админ-панели через веб-интерфейс (по умолчанию: http://localhost:8080).
Логин — Telegram ID + пароль (задаётся при установке или через
`python -m app.manage set-password`).

## Конфигурация
После установки настройте параметры в config.ini:

Бот
ini
[BOT]
token = ваш_токен_бота
admin_telegram_id = ваш_telegram_id
Платежи
ini
[PAYMENTS]
yoomoney_receiver = номер_кошелька_yoomoney
yoomoney_token = токен_приложения_yoomoney
yoomoney_notification_secret = секрет_http_уведомлений
Безопасность
ini
[SECURITY]
max_login_attempts = 5
lockout_duration_minutes = 30
## Безопасность
### 🔐 Безопасность паролей
Хеширование паролей PBKDF2 с солью

Минимальная длина пароля 8 символов

Блокировка аккаунта после 5 неудачных попыток

### 🛡️ Безопасность базы данных
SQLite с ограничениями внешних ключей

Защищенные права доступа к файлам (600 для config/базы данных)

Аудит-логирование всех действий администратора

### 🔒 Безопасность системы
Изоляция в защищенном виртуальном окружении

Проверка прав root для критических операций

Регулярные обновления безопасности

### Управление серверами
Система поддерживает интеграцию с 3x-ui для управления несколькими серверами. Через главное меню вы можете:

Добавлять новые сервера

Удалять существующие сервера

Просматривать список всех серверов

Управлять настройками каждого сервера

### Создание подписок
Через меню управления можно создавать ссылки для подписок, которые пользователи могут использовать для автоматической регистрации в боте.

### Обновление
Для обновления системы используйте:

~~~bash
sudo ./Boot-main-ini
Затем выберите пункт «3. Обновить панель» в меню или используйте скрипт обновления:

bash
sudo ./update.sh
Удаление
Для полного удаления системы:

bash
sudo ./uninstall.sh
Внимание: Это навсегда удалит все данные, включая пользователей, настройки и VPN конфигурации.
~~~

## Решение проблем
### Скрипт не запускается
Убедитесь, что скрипт имеет права на выполнение:

~~~bash
chmod +x Boot-main-ini install.sh uninstall.sh update.sh
~~~
### Ошибки зависимостей
Попробуйте переустановить зависимости вручную:

~~~ash
source venv/bin/activate
pip install -r requirements.txt
~~~

### Проблемы с базой данных
Восстановите базу данных из резервной копии (backups/) или выполните проверку/миграцию:

~~~bash
sudo ./venv/bin/python -m app.manage init
sudo ./venv/bin/python -m app.manage check
~~~

## Исправленная сборка

В этой сборке проект консолидирован: единственная реализация живёт в пакете `app/`
(бот, БД с ролями, серверы 3x-ui, тарифы, подписки, платежи YooMoney/CryptoBot,
веб-панель с парольным входом и ролевым доступом). Файлы в корне (`bot.py`,
`web_panel.py`, `admin_panel.py`, `database.py`, `config.py`, `payment.py`,
`xui_api.py`) остались как тонкие точки входа для совместимости.

Ключевые исправления:
- устранён конфликт двух реализаций бота/панели;
- повторный `/start` больше не сбрасывает баланс и роль пользователя;
- вход в веб-панель только по Telegram ID + паролю (см. `python -m app.manage set-password`);
- убран демонстрационный супер-админ с ID 1, роль администратора берётся из `admin_telegram_id`;
- схема БД приведена к единому виду, добавлены тесты (pytest).

Перед production-развёртыванием настройте `config.ini`, Telegram Bot Token, платёжные ключи и параметры серверов 3x-ui.

### Быстрый старт после установки

```bash
# Проверка конфигурации и базы данных
python -m app.manage check
# Выдать пользователю пароль для входа в веб-панель
python -m app.manage set-password <TELEGRAM_ID>
# Назначить роль: user | moderator | admin | super_admin
python -m app.manage set-role <TELEGRAM_ID> admin
```

Запуск всего стека (бот + панель): `python run.py`.
Только бот: `python bot.py`. Только панель: `python web_panel.py`.
